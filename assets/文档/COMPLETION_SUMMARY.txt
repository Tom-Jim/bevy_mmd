### 🧵 布料物理系统 (Cloth Physics)
```
✅ 算法        : Verlet积分 + 距离约束求解

✅ 性能        : 2-3ms (10k顶点 × 3迭代)

✅ 效果        : 衣服、布料、绳索自然摆动
```

### 💇 头发物理系统 (Hair Physics)
```
✅ 算法        : 骨骼链弹簧约束
✅ 特性        : 重力、刚度恢复、链式处理
✅ 性能        : 0.5-1ms (100条链 × 8骨骼)
✅ 参数范围    : stiffness [0.50-0.95], damping [0.90-0.99]
✅ 效果        : 头发、尾巴自然摇摆
```

## 🔧 集成方式

### 最小化改动
```rust
// main.rs - 只需改动调度链
.add_systems(FixedUpdate,
    (skin_update_system,
     apply_cloth_physics,  // ← 新增
     apply_hair_physics,   // ← 新增
     apply_skin_to_meshes)
    .chain()
    .after(PhysicsSystems::Writeback)
)
```

### 启用物理
```rust
// setup() 中添加
commands.spawn((physics::ClothPhysics { /* ... */ }));
commands.spawn((physics::HairPhysics { /* ... */ }));
```
