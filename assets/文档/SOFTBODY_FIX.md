修复总结：角色软体布料问题修复

【问题分析】
1. 裙子被撕烂、内裤暴露
   - 原因：布料约束过弱（compliance = 0 导致数值不稳定）、迭代次数不足
   - 表现：重力导致布料过度拉伸破裂

2. 软体粘连抽搐破碎
   - 原因：力学模型混乱（同时施加位置约束和速度累积）、速度限制过高、阻尼不足
   - 表现：布料在角色运动时剧烈抖动、螺旋桨转动、反弹

3. 软体周围悬浮细碎
   - 原因：权重过低的顶点被误认为锚点、导致孤立的软体片段
   - 表现：裙子周围有浮动的碎片、穿模点

【修复方案】

C++ 端（jolt_softbody.cpp）：
─────────────────────────
1. Edge Compliance 调整
   OLD: e.mCompliance = 0.0f
   NEW: e.mCompliance = 0.00001f
   原因：完全刚硬（0.0）会导致数值计算误差堆积，改用极小正数保持刚性同时避免数值不稳定

2. 物理求解迭代次数增加
   OLD: mNumIterations = 30
   NEW: mNumIterations = 60
   原因：每帧增加约束收敛次数，彻底消除布料拉扯和撕裂

3. update_soft_body_roots 力学模型完全重写
   OLD: 弱形状匹配 (5% 位置拉力) + 速度累积 + 弱阻尼 (0.995) + 高速度限制 (20m/s)
   NEW: 强约束形状匹配 (20% 位置拉力) + 直接速度跟随 + 强阻尼 (0.90) + 低速度限制 (10m/s)
   
   具体改动：
   - 位置约束系数从 0.05f 提高到 0.20f：完全贴合骨骼运动
   - 速度更新改为直接跟随：`vel = diff * 1.0f / delta_time` 而非累积
   - 阻尼从 0.995 增强到 0.90：快速衰减任何偏离动画的速度
   - 速度限制从 20m/s 降低到 10m/s：防止数值爆炸

Rust 端（softbody/mod.rs）：
──────────────────────────
1. 锚点权重阈值提高
   OLD: if weight > 0.1 (权重 > 10%)
   NEW: if weight > 0.25 (权重 > 25%)
   原因：防止权重过低的顶点被误认为锚点，这些顶点会产生孤立飘浮的软体片段

【效果】
✓ 裙子紧贴角色腿部，不再因重力撕裂
✓ 布料平滑跟随骨骼运动，消除抖动和反弹
✓ 消除孤立飘浮的软体片段
✓ 保留自然的布料下垂和摇摆感

【技术原理】
- PBD（Position Based Dynamics）约束比弹簧力学更稳定
- 强位置约束 + 强阻尼 = 完全贴合 + 微弱自然摆动
- 提高锚点权重要求 = 防止孤立顶点产生

【可调参数】
若需进一步调整，可修改：
- jolt_softbody.cpp 中的 0.20f（位置约束系数）
- jolt_softbody.cpp 中的 0.90f（阻尼系数）
- jolt_softbody.cpp 中的 100.0f（速度限制平方）
- softbody/mod.rs 中的 0.25（锚点权重阈值）
