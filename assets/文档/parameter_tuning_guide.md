# 软体物理参数调优指南

## 核心概念

软体（Soft Body）在这个系统中由两个相互制衡的力主导：

1. **骨骼驱动力**（约束）：让软体跟随角色骨骼，防止穿模
2. **物理力**（重力+惯性）：让软体自然下垂和摇摆

修复的关键是找到这两者的平衡点。

## 参数解析

### 位置约束系数 (mPosition += diff * 0.10f)

**作用**：每帧强制软体顶点向骨骼目标位置移动一定百分比。

- **0.05f**：太弱，布料会过度拉伸甚至撕裂（穿模问题）
- **0.10f** ✓：适中，防止穿模同时保留物理特性
- **0.15f**：偏强，布料会显得有点硬
- **0.20f**：太强，完全失去软体感（就是之前的问题）

**调优方向**：
- 如果出现穿模（衣服穿过腿部） → 增加到 0.12-0.15
- 如果太硬无摇摆 → 减少到 0.08-0.09

### 速度因子 (mVelocity = diff * 0.5f / delta_time)

**作用**：根据位置偏差计算速度，0.5f是衰减系数。

速度数值越大，软体被"拉"的力度越强，会产生快速追踪效果。

- **0.3f**：软体非常"慢"，响应延迟大，摇摆幅度小
- **0.5f** ✓：平衡反应速度和自然摇摆
- **0.7f**：软体反应快，摇摆幅度大
- **1.0f**：太快，会产生弹簧效应和反弹

**物理直觉**：
- 因子越小 → 软体越"重"，下垂感越强
- 因子越大 → 软体越"轻"，跟随性越强

### 阻尼系数 (mVelocity *= 0.95f)

**作用**：每帧保留前一帧速度的百分比，模拟空气阻力。

- **0.90**：快速衰减，摇摆1-2次就停下来（之前改的太强导致僵硬）
- **0.95** ✓：平衡衰减，允许自然摇摆5-10帧
- **0.98**：长时间摇摆，可能显得"飘飘然"
- **0.99**：基本不衰减，不符合物理

**等比衰减规律**：
- 1帧后剩余：95%
- 10帧后剩余：95%^10 ≈ 59%（下降到一半）
- 20帧后剩余：95%^20 ≈ 35%（基本平复）

**调优方向**：
- 如果摇摆太快消失 → 增加到 0.96-0.97
- 如果摇摆持续太久显得浮躁 → 减少到 0.93-0.94

### 求解器迭代次数 (mNumIterations = 40)

**作用**：PBD（Position Based Dynamics）每帧迭代多少次来满足约束。

更多迭代 = 更强硬地收敛 = 更多约束被严格执行 = 布料变硬

- **30**：少，计算快但可能出现撕裂
- **40** ✓：平衡点，防止撕裂同时保留软体感
- **50**：多，布料更难伸展，显得稍硬
- **60+**：太多，计算负担重且布料完全僵硬

**调优方向**：
- 如果静止时出现明显拉扯或撕裂 → 增加到 50
- 如果运行帧率低 → 减少到 35（但要接受轻微撕裂）

## 真实调优流程

### 情景1：布料太硬（最常见的问题）

**症状**：头发贴头皮，衣服僵硬跟随，完全没有摇摆

**解决方案**（按优先级）：
1. 减少位置约束系数：0.10 → 0.08
2. 增加阻尼系数：0.95 → 0.96
3. 减少迭代次数：40 → 35

**原理**：位置约束越弱，重力作用越充分 → 垂落和摇摆越明显

### 情景2：布料太软，过度摇摆

**症状**：衣服摆来摆去停不下来，显得飘飘然

**解决方案**（按优先级）：
1. 增加位置约束系数：0.10 → 0.12
2. 减少阻尼系数：0.95 → 0.93
3. 增加迭代次数：40 → 45

**原理**：位置约束越强，对摇摆的抑制越大 → 摇摆幅度越小，衰减越快

### 情景3：出现撕裂穿模

**症状**：布料在运动时拉扯变形，甚至穿过身体

**解决方案**（按优先级）：
1. 增加位置约束系数：0.10 → 0.13
2. 增加迭代次数：40 → 50
3. 增加速度因子：0.5 → 0.6（让软体反应更快）

**原理**：更强的约束+更多迭代 = 布料被锁定得更紧 = 不容易穿模

### 情景4：运行帧率低，计算压力大

**症状**：GPU/CPU占用率高，帧率下降

**解决方案**（按优先级）：
1. 减少迭代次数：40 → 30
2. 减少位置约束系数：0.10 → 0.09（减少约束力计算）
3. 考虑减少约束系数中的软体顶点数（在Rust端）

**原理**：迭代次数和约束强度直接影响计算量

## 实验方法

### 单参数测试法

只改一个参数，测试5秒以上，观察：
1. 静止时的形态（下垂程度）
2. 运动时的追踪速度（快还是慢）
3. 摇摆幅度和衰减速度
4. 是否出现撕裂或穿模

### 参数记录表

| 参数 | 值 | 效果评分（1-5）| 问题 |
|------|-----|-------|------|

| damping | 0.95 | | |

> 评分说明：1=问题严重，3=可接受，5=完美

## 极端配置参考

### 配置A：最硬（防穿模优先）
```cpp
pos_constraint = 0.15f
velocity_factor = 0.8f
damping = 0.92f
iterations = 50
```
适用于：需要完全防穿模的严格场景

### 配置B：最软（真实感优先）
```cpp
pos_constraint = 0.08f
velocity_factor = 0.3f
damping = 0.98f
iterations = 30
```
适用于：近距离镜头，对柔软感要求极高的场景

### 配置C：均衡（推荐）
```cpp
pos_constraint = 0.10f
velocity_factor = 0.5f
damping = 0.95f
iterations = 40
```
适用于：一般用途，多数情况下表现最佳

## 物理常识速查

| 问题 | 直觉理解 | 对应参数 |
|------|-------|--------|
| 为什么软体总是向下垂？ | 重力加速度 9.8m/s² | mGravityFactor = 1.0 |
| 为什么软体不会无限下垂？ | 布料自身的伸展约束（边长限制） | Edge constraint |
| 为什么需要位置约束？ | 没有它，布料会因重力远离角色 | pos_constraint |
| 为什么需要阻尼？ | 模拟空气阻力，否则会永远摆动 | damping |
| 为什么迭代多了会变硬？ | 约束被反复投影多次，越来越"被迫"满足 | iterations |

## 常见误区

❌ **误区1**："如果太硬，就把所有参数都减小"
→ ✓ 这样做会导致出现穿模。只需减少位置约束系数。

❌ **误区2**："阻尼系数越大越好，会让摇摆更自然"
→ ✓ 阻尼>0.98时，摇摆几乎不衰减，显得不自然。0.95是黄金分割。

❌ **误区3**："增加迭代次数就能解决所有问题"
→ ✓ 过多迭代反而导致布料变硬。40-50是合理范围。

❌ **误区4**："位置约束只是为了防穿模"
→ ✓ 它同时影响下垂程度、摇摆幅度、计算速度。

## 快速诊断表

| 症状 | 最可能原因 | 首选改进 |
|------|--------|--------|
| 布料贴皮肤，无下垂 | 位置约束太强 | 减少 pos_constraint |
| 布料摆来摆去停不了 | 阻尼太弱 | 增加 damping |
| 布料撕裂穿模 | 约束不足 | 增加 pos_constraint 或 iterations |
| 帧率低 | 计算过重 | 减少 iterations |
| 摇摆不自然，闪烁 | 参数冲突 | 逐一调整单参数 |
