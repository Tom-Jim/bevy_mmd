# 软体物理修复文档

## 问题描述

初始代码在运行时出现以下问题：

1. **布料刚硬无柔软感**：头发贴在头皮上，衣服僵硬不动，完全丧失了物理布料的特性
2. **缺乏自然垂落**：即使静止时，软体也不会自然下垂
3. **摇摆效果消失**：角色运动时，软体没有任何惯性摇摆，跟随刚硬如木

原因分析：之前的修改把位置约束改得过强（0.20f），导致软体变成了刚体被强制拉扯到骨骼位置。

## 修复方案

### C++ 物理引擎调整 (jolt_softbody.cpp)

#### 1. 迭代次数调整

```cpp
// 旧值: mNumIterations = 60
// 新值: mNumIterations = 40
```

**原因**：60次迭代导致约束过度收敛，软体完全被锁定。40次迭代在保证边约束防止撕裂的同时，允许重力和惯性充分作用。

#### 2. 力学模型重新设计

update_soft_body_roots 函数中的关键参数调整：

| 参数 | 旧值 | 新值 | 含义 |
|------|------|------|------|
| 位置约束系数 | 0.20f | 0.10f | 每帧向目标移动比例 |
| 速度因子 | 1.0f | 0.5f | 速度跟随强度 |
| 阻尼系数 | 0.90 | 0.95 | 速度保留比例 |
| 速度限制 | 10m/s | 10m/s | 保持不变 |

**物理原理**：

- **位置约束0.10f**：只做轻微约束，防止穿模但不强制锁定
- **速度因子0.5f**：速度被弱化到一半，让垂直方向的重力充分展现
- **阻尼0.95**：保留95%的速度每帧，允许较长的自然摇摆时间

### Rust 端参数 (softbody/mod.rs)

锚点权重阈值维持：`weight > 0.25`

**理由**：防止低权重顶点产生孤立飘浮的软体片段。

## 运行时效果验证

修改后，软体行为应该表现为：

1. **静止状态**
   - 头发自然下垂到肩膀
   - 衣服贴合身体，有明显的垂落弧线
   - 无僵硬或被强制锁定的感觉

2. **运动状态**
   - 角色快速移动时，头发和衣服产生明显的滞后效果
   - 软体惯性摇摆，不会立即跟随骨骼
   - 摇摆逐渐衰减回到骨骼驱动的位置
   - 整个运动过程自然流畅，无抖动或反弹

3. **约束效果**
   - 软体不穿过角色身体
   - 布料不会因重力撕裂
   - 边约束防止过度拉伸

## 技术要点

### 为什么需要适度约束而不是强约束？

1. **物理真实性**：真实布料在被拉扯时会有延迟和摇摆，不会瞬间跟随
2. **计算稳定性**：过强的约束导致数值震荡和人工感
3. **性能**：适度约束比强约束的迭代次数需求少，效率更高

### 重力为什么那么重要？

- 位置约束只占10%的驱动
- 重力通过 `mGravityFactor = 1.0f` 充分作用
- 这样软体既能跟随角色（防穿模），也能下垂摇摆（物理真实）

### 边约束参数解释

- `compliance = 0.00001f`：极小但非零，防止数值刚性导致的误差堆积
- 这比完全刚硬(0.0)更稳定，同时保持边长约束

## 可调参数列表

若效果不理想，可调整以下参数（在jolt_softbody.cpp中）：

```cpp
// 位置约束强度（范围：0.05-0.15）
vertices[v_idx].mPosition += diff * 0.10f;  // 调这个值

// 速度因子（范围：0.3-0.7）
vertices[v_idx].mVelocity = diff * 0.5f / std::max(delta_time, 0.0001f);  // 调这个值

// 阻尼系数（范围：0.92-0.98）
vertices[v_idx].mVelocity *= 0.95f;  // 调这个值

// 求解器迭代次数（范围：30-50）
creation_settings.mNumIterations = 40;  // 调这个值
```

**调试指南**：
- 如果软体太软（过度摇摆）→ 增加位置约束系数 或 减少阻尼系数
- 如果软体太硬（无法摇摆）→ 减少位置约束系数 或 增加阻尼系数
- 如果出现撕裂 → 增加迭代次数
- 如果计算太慢 → 减少迭代次数
